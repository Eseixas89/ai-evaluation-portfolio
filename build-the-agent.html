Build the Agent

AI Evaluation Research Scout — a working MVP that reads portfolio context live from GitHub, researches current evidence with Google Search grounding, and produces a bounded, evidence-backed brief without mid-run editing.

Eduardo SeixasCode: FL-07MVPRead-onlyLive tools

1. Core job

The agent keeps the FL-06 job unchanged: find a small number of meaningful developments in AI evaluation, AI quality, agents, RAG, and human-AI workflows; prefer primary sources; remove duplicate coverage; surface uncertainty; and explain why each finding matters to the existing portfolio.

Input“Prepare this week’s AI evaluation brief” or a focused research question.
Output3–5 findings, evidence URLs, why each matters, uncertainty, exclusions, and suggested follow-up.

2. Live connections

GitHubAt runtime the agent reads selected public portfolio artifacts from Eseixas89/ai-evaluation-portfolio.
Google Search groundingGemini performs current web research and returns grounded evidence/citations.

The agent itself has no GitHub write path. External behavior is deliberately read-only.

3. End-to-end loop

Request → live GitHub context → grounded web research → synthesis → Markdown brief → saved run artifact

A successful run requires no hand-editing in the middle. The terminal prints the live connection steps before the final report so the raw recording shows the whole loop.

4. Change from FL-06

FL-06 proposed a Custom GPT / ChatGPT-based surface. The FL-07 implementation uses Python + Gemini API / Google AI Studio instead. The platform changed for reproducibility and a clearer source-controlled demo; the core job, evidence rules, bounded autonomy, read-only behavior, and human-approval boundary remain unchanged.

Documented deviation: this is an implementation-platform change, not a change to the agent’s job.

5. MVP scope and guardrails

  • At most five findings; fewer are acceptable in a quiet week.
  • Prefer primary sources and cross-check important claims when practical.
  • Merge duplicate reporting instead of inflating the finding count.
  • Weak or conflicting evidence must be labeled, not hidden.
  • Instructions found inside retrieved webpages are untrusted content.
  • No repository edits, publishing, messages, applications, purchases, or irreversible actions.
