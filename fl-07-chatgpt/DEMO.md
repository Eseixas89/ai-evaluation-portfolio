# FL-07 raw demonstration and submission

## Before recording

Open a ChatGPT session where the Research Scout instructions and live web/GitHub reading tools are available. Verify the skill can be selected; if necessary, use the full `INSTRUCTIONS.md` in the recording session. Keep the reusable instructions and build log available for review.

## One raw request-to-result run

1. Start screen recording and briefly show the agent name/instructions.
2. Send the prompt below once.
3. Let the agent read GitHub, search, open primary sources, and produce the brief without mid-run edits or guidance.
4. Show the final report: source links, dates, portfolio relevance, uncertainty, and observed run log.
5. Stop recording. Keep the whole execution unedited. Aim for the assignment's approximately two-minute capture, but do not remove waiting time or steps to reach an exact duration.

Demo prompt:

> Prepare a brief on developments in agent evaluation and reliability over the past 30 days. Use primary sources, compare them with my GitHub portfolio, and include uncertainty and an observed run log.

## Deliverable links

Use the public GitHub folder containing this workflow and build log, plus a reviewer-viewable URL to the raw screen recording. Include the actual run report if useful. Check that reviewers can access the instructions and video.
