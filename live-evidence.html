    Behind this feature

    What happens after the click?

    A backend is the part of a service that runs on a server and responds to requests. GitHub Pages serves this portfolio's HTML, CSS, and JavaScript. It does not run a custom application backend here. This feature uses GitHub's existing API as its external backend.

    1. You choose a project and press Load live evidence.
    2. The JavaScript in your browser asks the GitHub API for the current commit on main, then requests the file tree at that exact commit. Both responses are JSON: structured text the page can read.
    3. The browser selects the files belonging to that project and displays their paths, sizes, and links. Each link points to the same commit, so the evidence stays traceable even if the repository changes later.

    There is no AI model call, database, contact submission, or private credential in this demo. It sends two read-only requests to GitHub for a fresh snapshot and keeps that snapshot in this tab's memory for five minutes. GitHub receives ordinary web-request information such as the visitor's IP address. Nothing is saved by this page after the tab is closed.

    The portfolio is hosted on GitHub Pages using a public repository, and the API reads public data without a paid service or key. Unauthenticated API requests are generally limited to 60 per hour per IP address. If GitHub is unavailable, a request times out, or the limit is reached, the page displays an error and keeps a direct repository link available.

    Explicação em português

    Backend é a parte de um serviço que funciona no servidor e responde às solicitações. Neste projeto, o GitHub Pages entrega a página e a API do GitHub fornece os dados. Não existe um servidor próprio executando Python ou um modelo de IA.

    Ao escolher um projeto e clicar no botão, o navegador busca o commit atual e a lista de arquivos daquele commit. O JavaScript filtra os arquivos do projeto e mostra os links para aquela versão. São duas consultas de leitura. O resultado fica na memória da aba por cinco minutos para reduzir consultas repetidas. Se a consulta falhar, aparece uma mensagem com acesso direto ao repositório.

    A função demonstra uma consulta real a um serviço externo. Ela não avalia automaticamente a qualidade dos projetos; permite que o visitante inspecione as evidências.
