How my portfolio gets published

One part of my build I wanted to understand better was how pushing my files to GitHub actually turns them into a live website.

My project has a GitHub Actions workflow that watches the main branch. When I push a change there, GitHub starts the workflow automatically. It first gets a copy of the repository, prepares GitHub Pages, packages the website files, and then deploys that package.

What helped me understand it is that GitHub is not simply showing my HTML file from the repository. The workflow is the bridge between the code I keep in the repository and the version people can open as a website.

So now I understand that changing the site and publishing the site are two different steps: I change the files, push them to main, and the deployment workflow takes care of making that new version live.
